# Product Overview

XGCERP (XGCERP) is a full-featured, open-source ERP system built on the Frappe Framework. It covers accounting, order management, manufacturing, asset management, CRM, projects, stock/inventory, buying, selling, support, and quality management.

The application is a Frappe "app" — it extends the Frappe web framework and relies on Frappe for ORM, authentication, REST API, background jobs, and the web UI shell.

Key business domains:
- **Accounts**: GL, invoicing, payments, bank reconciliation, budgets, tax, deferred revenue
- **Stock**: Warehouses, serial/batch tracking, valuation, reorder, stock entries
- **Manufacturing**: BOM, work orders, job cards, subcontracting
- **Buying / Selling**: Purchase and sales cycles (quotation → order → invoice)
- **CRM**: Leads, opportunities, email campaigns, contracts
- **Assets**: Asset lifecycle, depreciation, maintenance
- **Projects**: Tasks, timesheets, project billing
- **Support**: Issues, SLAs, warranty claims
- **Regional**: Country-specific tax and compliance (Italy, UAE, Saudi Arabia, France, etc.)
